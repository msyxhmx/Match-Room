# Wireframes

- `match-room.excalidraw`: the eight live-screen sketches and the chosen layout B. Open it at
  [excalidraw.com](https://excalidraw.com) via Menu → Open, or drag the file onto the canvas.
- `sketches.json`: the sketch layouts in 1920×1080 coordinates. This is the source for the file above.
- `to-excalidraw.mjs`: regenerates the Excalidraw file:
  `node web/wireframes/to-excalidraw.mjs web/wireframes/sketches.json web/wireframes/match-room.excalidraw`

The reasoning and the full grey wireframes are summarised in [DESIGN.md](../DESIGN.md) §9.9.
