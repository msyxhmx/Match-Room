# Demo script (about 2:00) — draft

Run the `comeback` scenario (`SCN-comeback`) at `speed=60` so the match plays in 90 seconds;
pause the stream if needed by reconnecting with `from_minute`.

1. **Problem (0:00–0:15)**: Studios serves 189 markets; fans get numbers, not reasons, and
   rarely in their language.
2. **Live (0:15–0:50)**: kick off the comeback. At 14' the first goal arrives flagged *against
   the run of play*; open "Facts used" and the evidence to show every number is traceable.
   Point at the control vs chaos bar as the game breaks up.
3. **Same moment, three ways (0:50–1:10)**: switch the stream to Malay casual, then analyst
   English (PPDA, xT, definitions), and show the overlay message a studio graphics system would
   receive.
4. **Half-time brief (1:10–1:30)**: 0-2, "what happened / why / what to watch", the explained
   projection (not odds).
5. **Full time (1:30–1:45)**: "Northgate City come from behind to win 3-2", turning points with
   win-chance swings, player of the match; flash the season storylines.
6. **How it's built (1:45–2:00)**: five-stage pipeline, synthetic data, validator, Azure
   OpenAI as an optional rewriter that can never add an unproven number.
